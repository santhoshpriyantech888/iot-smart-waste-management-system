# 🌐 IoT Smart Waste Management System

## 📌 Overview
An IoT-based smart dustbin that monitors waste level and automatically opens the lid using sensors.

## 🎯 Objective
To improve waste management efficiency and hygiene using automation.

## 🛠️ Technologies Used
- Arduino
- Ultrasonic Sensor
- IR Sensor
- Servo Motor
- Blynk (IoT platform)

## ⚙️ Features
- Automatic lid opening (contactless)
- Real-time waste level monitoring
- Smart waste detection

## 🧩 How It Works
- Ultrasonic sensor measures distance of waste
- Converts it into percentage level
- IR sensor detects user presence
- Servo motor opens/closes lid
- Data can be sent to Blynk for monitoring

## ▶️ How to Run
1. Connect sensors to Arduino
2. Upload code using Arduino IDE
3. Open Serial Monitor
